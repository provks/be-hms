# Healthcare Management System (HMS) - Backend

This is the backend API for the **Healthcare Management System (HMS)**, built using **Node.js** and **Express**. It handles authentication, patient records, doctor schedules, and appointment bookings.

## 🚀 Quick Start

### 1. Prerequisites
Ensure you have **Node.js (v18+)** and **npm** installed.

### 2. Installation
Clone the repository and install the dependencies:
```bash
git clone <your-repository-url>
cd hms-backend
npm install
```

### 3. Environment Setup
Create a `.env` file in the root directory and add your configurations:
```env
PORT=5000
DATABASE_URL=your_database_connection_string
JWT_SECRET=your_jwt_secret_key
```

### 4. Run the Application
```bash
# Run in development mode (with nodemon)
npm run dev

# Run in production mode
npm start
```

## 🛠️ Tech Stack
* **Runtime:** Node.js
* **Framework:** Express.js
* **FrontEnd Framework:** Bootstrap
* **Database:** MongoDB 
* **Authentication:** JSON Web Tokens (JWT)
